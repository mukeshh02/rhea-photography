# Liller Photo - Local Clone

Complete offline clone of https://lillerphoto.com/ running on http://localhost:3003.

## Features Cloned:
- **All 89 Pages**: Home, About, Weddings, Engagements, Lifestyle, Investment, Contact, FAQ, Client Guides, Album Options, Portraits, and all Blog posts.
- **Typography & Font Styles**: Showit custom web fonts (`hv_fitzgerald_bold_italic.woff`, `hv_fitzgerald_bold.woff`, `hv_fitzgerald_italic.woff`, Google fonts Montserrat, Lato, Playfair Display).
- **Core Engine & Animations**: Localized Showit engine scripts, CSS, and jQuery.
- **High-Resolution Images**: Hero images, logos, galleries, and portfolio showcases.
- **Port**: Runs independently on `http://localhost:3003`.
